# TRON 扫描器地址同步实施计划

## 1. 目标

将 `wallet-chain-server` 中需要监控的 TRON 地址同步到扫描器内存，并在地址已经对扫块线程可见后确认监控水位。

## 2. 系统边界

### wallet-chain-server

- 管理地址及其状态。
- 提供币种配置和地址增量同步接口。
- 接收扫描器应用水位 ACK。
- 将已确认监控的地址从 `PENDING_MONITOR` 更新为 `ACTIVE`。

### wallet-tron-scanner

- 调用链服务同步币种和地址。
- 校验地址并构建只读内存快照。
- 原子替换当前地址快照。
- 快照生效后确认最大 `addressId`。
- 不读取链服务数据库，不接收 `keyRef` 和用户绑定信息。

## 3. 开发顺序

1. 在 `wallet-chain-server/chain-client` 定义币种查询、地址增量查询和 ACK 契约。
2. 在 `wallet-chain-server` 实现三个内部接口及网络校验。
3. 在扫描器实现 `ChainServerClient`。
4. 实现紧凑、只读并可原子替换的地址快照。
5. 实现分页同步流程，只有快照替换成功后才发送 ACK。
6. 增加 `AddressSyncJob`，由 XXL-JOB 串行触发。
7. 测试重复同步、分页中断、ACK 失败、服务重启和百万地址内存占用。

## 4. 当前阶段不实现

- TRON 扫块和区块检查点。
- TRX、TRC20 交易解析。
- 充值交易上报。
- 节点健康检查与自动切换。
- 地址与用户绑定关系。
